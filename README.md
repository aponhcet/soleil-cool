# Rendre le soleil cool à nouveau ☀️

Projet perso : le soleil en chiffres vérifiés, en scrollytelling rétro‑futuriste années 70 (compteurs mécaniques, soleil plat rayé, curseurs interactifs). FR + EN.

- Site statique : `index.html`, `style.css`, `app.js`, `data.js` (constantes sourcées et validées).
- `node calc.js` recalcule toutes les valeurs dérivées affichées.
- Aucun son, aucun traceur, aucun cookie. Respecte `prefers-reduced-motion`.
- Sources visibles près des chiffres (« source » → `#src-N`) ; liste complète en bas de page (UAI 2015 B3, NASA NSSDC, Energy Institute 2025, GIEC AR6 & SRREN, Fraunhofer ISE, LANL, NIST…).
- Chapitre « pile de centrales » : **pyramide** en rangées étagées (SVG + odomètre temps-soleil) — `pile.js` / `pile.css`.

Live : https://aponhcet.github.io/soleil-cool/ (branche `gh-pages`).
